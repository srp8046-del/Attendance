Upload the original Employee Master CSV, BIO Excel report and TOS CSV. BIO Excel is cleaned automatically after upload.

BIO format handled: the workbook can contain two sheets. Each sheet is read employee-by-employee from its monthly report blocks: Employee Code → day row → Status → In Time → Out Time → T Duration. It is converted internally into one clean row per employee per date.
